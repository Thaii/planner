# Planner pals

`chars.py` draws the original Cute-style characters as SVG: the main pals (Snoozy, Pip, Dewy, Sprig, Sunny, Luna, Twinkle, Bellsy) and the section pals (Dottie, Stickle, Inchy, Mimi, Brocco, Cuppy, Bloom, Zip, Puff, Chai, Hugs).
`src/components/pals.tsx` holds the generated SVG; regenerate it from these functions after changing a character.
